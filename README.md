# Neural Circuits and Adaptive Stimulation Lab (NCAS Lab)

Static website for the Neural Circuits & Adaptive Stimulation Lab (NCAS Lab), Department of Cognitive Neuroscience, Maastricht University.

## Local preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

This site has no build dependencies. In **Settings → Pages**, choose **Deploy from a branch** → `main` / root.
